FIELD GUIDE / 07

How to read the observatory

01Choose an encounter

Select an object in the index to see its source-reported close approach, miss distance, and velocity.

02Read distance in context

LD is the nominal Earth–Moon distance convention (384,400 km). It is a scale comparison, not a risk score.

03Understand the field

Markers and paths are normalized schematic guides unless a view explicitly says that it uses propagated ephemerides.

04Check provenance

Use the data-provenance panel to distinguish live data from cached results or unavailable feeds.
