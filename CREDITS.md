# Credits and external dependencies

Ecliptara contains original application markup, styles, JavaScript, and an original SVG wordmark. It uses the following external services, software, and imagery:

- **NASA NeoWs** for near-Earth-object close-approach data: https://api.nasa.gov/ and https://data.nasa.gov/dataset/asteroids-neows-api
- **NASA Blue Marble: Next Generation** Earth base imagery: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/
- **NASA APOD Basic** for the astronomy image and description: https://science.nasa.gov/wp-json/wp/v2/apod-basic/
- **Launch Library 2** for upcoming launch schedules: https://thespacedevs.com/llapi
- **Three.js** and its OrbitControls module: https://threejs.org/
- **Google Fonts**: Space Grotesk, Manrope, and DM Mono: https://fonts.google.com/

Use the external APIs and assets according to their current terms, limits, and source-specific attribution requirements. Do not imply NASA, JPL, or Launch Library 2 endorsement. The source-linked NASA texture is remotely loaded; the project does not redistribute a local copy of it.
